# 防御工事经验升级系统 + 新设备「箭塔」设计方案

日期：2026-10-30 · 状态：**已定稿（作者 2026-10-30 批准）** · 目标 mod：SurvivalLog.EndlessGuard

> 定稿所含作者决议：四表 ID 用 99xxx 预留段（箭塔=99005）；升级阈值加大版 1200/3600/8400/16800 + 沙包承伤系数×2.0；箭塔玻璃炮定位（攻14/1.5s/射程 3.0→5.2/HP100/无减伤成长）；等级显示=样式A 悬停详情；模型=程序化精致木塔 v2（借鉴经典策略游戏）；弹道为表现层必命中。"攻击间隔=缩短"与"mod 本地 JSON 持久化"两项自首轮提出后历经多轮评审无异议，随定稿默认接受（实施期间可随时经 cfg/修订推翻）。

## 1. 背景与目标

无尽模式后期尸潮轮番进攻、防御撑不住，游戏进行不下去。本方案给防御系统加两层成长：

1. **设备经验升级**：四件套防御设备（沙包/尖刺/电网/电锯）在战斗中积累经验、自动升级，变强并回满耐久——防线越打越硬，形成"以战养防"的正循环。
2. **新攻击设备「箭塔」**：远程物理输出位，攻击略低于电锯、攻击间隔略长于电锯、射程更远，补上"远程点名"生态位。

### 非目标

- 不改官方存档结构、不写游戏存档数据（套件红线）。
- 不做全新特效/音效资产（一期借用现有资源或留空，见 §4.5）。
- 不做设备升级的 UI 面板（一期用悬浮名/头血条 + trace 自证，UI 二期再议）。
- 不平衡性改动官方四件套基础数值（升级系统只做加法）。

- `TowerDeviceComponent`（逐家具实例，`Battle.Logic`）：`Attack`、`AttackIntervalSeconds`、`AttackRangeSqr`、`MaxHitTargets`、`CounterDamage`、`SelfDamagePerBite` 等**属性全部可写**（interop setter 直调，非 Harmony 属性补丁，符合红线7）。设备配置在 `OnInit(furnitureConfigId)` 快照进组件——升级直接改组件，不影响同类型其他个体。

## 3. 功能A：设备经验升级系统

### 3.1 规则

- **经验来源**：
  - 沙包：承受伤害 1:1 计经验（被咬越狠、经验越多）。
  - 尖刺：反伤/残骸扎伤的伤害值计经验。
  - 电网/电锯（及箭塔）：每次开火按命中伤害计经验（`Attack × 命中目标数`，天赋加成前的面板值，实现期若可低成本取实伤则取实伤）。
  - 击杀追加：击杀目标时按该次伤害 ×50% 追加经验（可 cfg 关闭）。
- **自动升级**：经验达阈值即升级，无手动操作。
- **升级效果**（瞬时）：血量上限提升 + **回满血**（`AddMaxDurability` 后 `AddCurrentDurability` 补满）；攻击提升、攻击间隔缩短（仅武器类）；受击伤害降低（"防御"，全部四类）。

> ⚠️ 需求原文"升级后增加…攻击间隔"按语意修正为**缩短攻击间隔**（攻速加快）；若作者本意确为"拉长间隔"请否决本条。

### 3.3 持久化（新事物，需作者认可）

等级/经验为 mod 私有数据，存 `BepInEx/plugins/EndlessGuard_data/device_levels.json`：
`{ 存档标识: { 设备键: { xp, lv } } }`。

- **设备键默认方案**：`家具ConfigId + 安放格子坐标`（玩家搬动设备会掉级——文档明示；搬动是低频操作，可接受）。实现期若确认 AgentSave 实例 ID 跨读档稳定（`LoadGame(AgentSave, Dictionary<long,long> mapSearcher)` 的重映射语义），则改用实例 ID。
- 设备**耐久本身走官方存档**，无需 mod 管理血量。
- 读档后 GuardTicker 幂等重放：按等级把组件属性从当前值校准到 `基础值 × 等级系数`（记录注入的等级差值防重复叠加）。
- 卸载 mod：删 dll 即可，json 残留无害；设备属性回官方基础值。

### 3.4 实现锚点

| 事件 | 锚点 | 手法 |
|---|---|---|
| 沙包受击经验+防御减免 | `FurnitureDurabilityComponent.TakeDamage` | 前缀：名单内设备且 `isRepair=false` 时按等级缩放伤害入参；后缀：按实际扣血计经验 |
| 武器开火经验+击杀判定 | `TowerCombatManager.FireDevice` | 前缀快照目标 HP；后缀：按 `Attack×目标数` 计经验、HP 比对记击杀加成 |
| 尖刺反伤经验 | `TowerCombatManager.ApplyZombieBite` | 后缀：按 `CounterDamage` 记反伤经验 |
| 尖刺残骸经验 | `TowerCombatManager.HitZombieByWreck` | 后缀计经验 |
| 升级生效 | 经验结算处就地执行 | 直写 `TowerDeviceComponent` 属性 + `AddMaxDurability/AddCurrentDurability` |
| 读档重放 | GuardTicker 2s 巡检 | 幂等校准（哨兵=组件当前值≠应然值即重放） |

注意：升级写组件属性后若官方某处从配置重快照（如修理完成、读档），巡检重放兜底恢复。

## 4. 功能B：箭塔

### 4.1 定位与数值（**待审批**；作者 2026-10-30 改定定位：**高攻击、远射程、高射速、低防低血**的玻璃炮，取代最初"攻击略低/间隔略高"方案）

生态位：**远程单体高伤速射玻璃炮**。电锯=近距范围绞肉机（单体 DPS 6 / 四目标 24，皮糙），箭塔=后排速射点名（单体 DPS 9.3，射程 2 倍于电锯，但血量减半且无防御成长）——输出换生存，被摸到就疼。

| 字段 | 箭塔 | 对照电锯 | 说明 |
|---|---|---|---|
| Attack | 14 | 12 | **高于电锯**（高攻击 ✅） |
| AttackInterval | 1.5s | 2s | **快于电锯**（高射速 ✅） |
| AttackRange | 3.0 | 2.5 | **3 格半径起步**（远射程 ✅，随级成长） |
| MaxHitTargets | 1 | 4 | 单体点名（对群短板，平衡项） |
| HitSlow | 0 | – | 箭矢不减速 |
| IsWalkThrough | true | true | 不阻挡（不改变现有布防迷宫） |
| MaxAttackers | 3 | 3 | 可被咬 |
| HP（FurnitureHPMax） | **100** | 200 | **电锯一半**（低血量 ✅） |
| PowerCost（持续） | 6 | 5 | 输出税，高于电锯 |
| PowerCostPerHit | 2.5 | 3 | ≈1.67/s vs 电锯 1.5/s |

**逐级成长表（箭塔特化规则，基础 攻14/间隔1.5s/射程3.0/HP100）**：攻击 +15%/级、间隔 −8%/级、**射程 +0.55 格/级（Lv1=3.0 → Lv5=5.2，作者 2026-10-30 拍板端点）**、HP +15% 基础值/级（低成长保持脆皮）、**无受击减免成长**（低防御定位）、升级瞬间回满血。其余武器类（尖刺/电网/电锯）不涨射程。

| 等级 | 攻击 | 间隔 | DPS(单体) | 射程 | HP上限 | 受击伤害 |
|---|---|---|---|---|---|---|
| Lv1 | 14 | 1.50s | 9.3 | 3.0 | 100 | 100% |
| Lv2 | 16.1 | 1.38s | 11.7 | 3.55 | 115 | 100% |
| Lv3 | 18.5 | 1.27s | 14.6 | 4.1 | 130 | 100% |
| Lv4 | 21.3 | 1.17s | 18.2 | 4.65 | 145 | 100% |

**射程换算（1 世界单位 = 1 家具格）**：判定基准为设备中心到僵尸中心距离（`AttackRangeSqr` 比距离平方；是否从边界起算实现期 spike 验证）。依据：僵尸咬击射程 0.5（半格）、喷吐僵尸 2.5、电网 1.5、电锯 2.5 的相对关系自洽。

| 设备 | 射程 | 覆盖（以设备为中心） |
|---|---|---|
| 电网 | 1.5 | 自身格+一圈（3×3 减角，约 9 格） |
| 电锯 | 2.5 | 2 格半径（5×5 减角，约 21 格） |
| **箭塔 Lv1** | **3.0** | **3 格半径（约 28 格，电锯的 1.3 倍）** |
| 箭塔 Lv5 | 5.2 | 5 格半径（约 81 格，全场大半纵深） |

合理性判据：① 防御格按四排（MapSlot.TowerRow）布防，3.0 起步覆盖相邻排通道，随级扩到全场大半纵深；② **喷吐僵尸（射程 2.5/1.5）从 Lv1 起即可在其射程外反制**，满级 5.2 反压一切远程怪——玻璃炮的战术价值随等级逐步兑现。

### 4.4 动作设计（零 Animator 依赖，mod 代码驱动）

- **待机**：弩机头部缓慢左右扫描（±15°，2s 周期）；红旗持续小幅摆动（±16°，0.9s 周期）。
- **索敌/开火**：FireDevice 后缀里把弩机头部 Y 轴转向最近命中目标（每帧 lerp，角速度上限 120°/s）；开火瞬间托身+导轨+上膛箭整体后坐回位（0.07 位移三角波 0.2s）。
- **弹道=纯表现层，必命中（作者 2026-10-30 验收要求）**：伤害结算在 `FireDevice` 内部即时完成（hitscan，官方机制），箭矢只是 mod 补的视觉弹道——**从弩机插值飞向"实际受击目标的实时位置"（追踪式）**，终点锚定受击者，不存在射空；飞行上限 0.25s 强制到点消散，目标中途死亡则在死亡位置消散。预览页早期版本为直线飞行演示（会脱靶）已修正为追踪式。
- **被摧毁**：沿用官方 `SyncTowerDeviceModelState` 禁用态（模型整体下沉+变灰由官方 FSM 处理，实现期验证表现，不足则 mod 补）。

### 3.6 生命周期裁定（builder check 补充，我的处理）

- **设备被摧毁**：经验账目是 mod 侧字典，不依赖组件存活——设备死后该格子条目**保留**，原格重建同类型设备**继承等级与经验**（尸潮拆了 Lv4 沙包、重建即 Lv4：贴合"防线越战越强"诉求，重建照常花材料，无刷经验漏洞）。拆除（非摧毁）同样保留条目；换建其他类型设备不继承。
- **尖刺残骸经验**：残骸扎伤继续记账（条目在即可记），重建后生效。
- **击杀归属**：`FireDevice` 前缀快照各目标当前 HP、后缀比对得出击杀数（不依赖死亡事件钩子），击杀加成默认开启；若实测前后缀间隔内目标 HP 不可读（IL2CPP 取值异常），降级为纯伤害经验并在 cfg 置 KillBonusRatio=0。
- **反伤经验锚点补全**：§3.4 增补 `TowerCombatManager.ApplyZombieBite` 后缀（咬击事件内按 `CounterDamage` 记尖刺反伤经验）。
- **修理费随血量上限放大**（官方 `BuildRepairCost` 按缺失耐久/上限计费）：**接受并文档化**——血池变大修理账单相应变大是公平的；组件 `RepairCostRatio` 可写，留作日后 cfg 钩子。
- **防御减免前缀过滤**：`TakeDamage(int, bool isRepair, string, bool)` 前缀只缩放 `isRepair=false` 的敌意伤害，`isRepair=true` 的回复路径原样放行（防止"升级=修理"漏洞）；加入 §6 验证项。
- **存档标识**：优先 `GameSaveManager.SaveFileName`/无尽 ResumableEndlessSave 文件名（实现期验证稳定性）；极端兜底=全部存档共用一本经验账（差距可接受，因设备等级绑定格子坐标）。
