## 未定号（2026-11-02 起，待作者定版）

- **修复：箭塔/已升级设备被僵尸咬 0 伤（耐久永满）**：
  - 症状（playtest 实锤）：箭塔从摆下起耐久永远是满的（尸潮啃不动）；沙包升到 Lv.2 后从此不掉血
    （承伤经验也断流，卡死 Lv.2）
  - 根因（反汇编定案）：官方僵尸咬塔设备的伤害不走设备配置行，走 GlobalSetting 表
    `TowerZombieAttackDevice` 行的 Params3 串（`僵尸id:设备id:伤害` 分号串），官方串只含
    36001~36004——箭塔 99005（本 mod 注入）与全部升级派生行 99112~99155 查表必 miss = 0 伤免疫
  - 修复：启动后自动把箭塔（99005 及 Lv2~5 行）与五类设备的全部派生行追加进该串（伤害按官方
    参照值 × 各自减伤系数缩放，箭塔 1.0 不减，下限 1）；官方解析器自动收编，僵尸开始正常啃咬
  - 附带修正：派生行减伤成长（武器 −10%/级、沙包 −12%/级）此前实际未生效（误载于不承载咬伤的
    SelfDamagePerBite 字段），本修复起落到攻击规则值上

- **修复：自动保存换档名导致全队等级被打回 Lv.1（账本槽误切换）**：
  - 症状（playtest 实锤）：进档后设备等级回 1、数值回原厂（trace 一次性 recal lv=1 ×N，lv5 箭塔
    99155→99005）；同一局的账目被劈进多个档名槽（Save_时间戳各不同），真账（如箭塔 lv5/xp16 万）
    躺在旧档名槽里无人认领
  - 根因：游戏自动保存会创建新档名文件，GetLastPlayFileName 随即返回新名——mod 把"保存了一下"
    误读成"换了个档"，账本槽跟着切换，全体设备账目瞬间 miss，巡检按 lv1 打回基础行
  - 修复①：账本槽改为**进档锁定**（世界从无到有的瞬间确定一次，整局不变；Award/悬停里的随取
    随刷全部移除）——此后自动保存/手动另存与等级记录彻底无关
  - 修复②：进档后一次性**跨槽账目融合**（其余槽同键账按 xp 最大并入本槽）——此前被劈散的真账
    自动收回，失而复得的等级当场生效（trace `[XP] slotMerge +N 条` 可查）

- **修复：设备等级/耐久"来回跳跃"（账本键抖动分裂）**：
  - 症状（playtest 实锤）：尸潮中已升级设备的等级名（Lv.2↔Lv.3↔Lv.4）与耐久上限来回跳，
    trace 每 2 秒成批 `recal` 刷屏
  - 根因：经验账本按"设备位置格坐标"记账，机械电锯等设备的模型原点恰在格线 .5 边界
    （x≈12.5/4.5/8.5），战斗帧位置读数微抖即令四舍五入在两格间横跳——同一台设备的经验被劈进
    两条账（如 `12,-21` 与 `13,-21`），两条账各自升级、巡检各自"纠偏"，配置行被来回推
  - 修复：cellKey 首次绑定后粘住（同设备同键），坐标真搬离 ≥1 格才换键；读档/换档绑定表清空。
    ε 级读数抖动不再分裂账本，战斗中等级/耐久稳定单线
  - 诊断增强：`recal`/`lvup` trace 带 `cell=` 键与旧行号，同类问题下次可直接定位
  - 已分裂的旧账（成对相邻条目）不自动合并：修复后设备会稳定绑定其中一条，另一条成为死账
    （无害；介意历史等级差异可开一次 `Defense.ResetLevels` 清账重攒）

## 1.8.0（2026-11-01）

- **新功能：防御设备经验升级**（spec `docs/superpowers/specs/2026-10-30-defense-upgrade-arrowtower-design.md`）：
  - 五件防御设备（沙包/尖刺障碍/电网/机械电锯/箭塔）打怪、承伤、击杀攒经验逐级成长：武器类
    攻击 +15%/级、攻击间隔 −8%/级（下限 60% 基础间隔）、耐久 +30%/级、受伤 −10%/级；沙包专精
    血牛（耐久 +25%/级、受伤 −12%/级）；箭塔另加射程 +0.55 格/级（Lv1 3.0 → Lv5 5.2）。
    升级瞬间回满血；阈值 1200/3600/8400/16800（一波普通尸潮升不满）
  - 悬停设备名显示「Lv.N · 升级 x/y」（满级 Lv.N MAX，cfg Defense.ShowLevel 可关）
  - 读档/修理后 2 秒巡检幂等校准（升级属性不丢）；连续 3 次不收敛自动熔断（封死回血循环）
  - 数据存 mod 本地 JSON（`BepInEx/plugins/EndlessGuard_data/device_levels.json`），零游戏存档
    写入，删 dll 读档即还原官方原厂数值
  - cfg：`Defense.XPEnabled` 总开关 + 倍率/阈值缩放/等级上限/击杀比例/沙包系数/各类成长步长
    共 13 键可调（改动即时生效，步长类 2 秒内对已升级设备自动重算）
- **新防御设备：箭塔（ID 99005）**：
  - 工作台配方「箭塔包裹」（木片×2 + 铁皮 + 碎玻璃），防线 Lv4（工事技师）解锁，四表内存注入
    （塔数值/家具/包裹/配方，99xxx 预留段防官方撞号）
  - 定位高攻速射远射程单体玻璃炮：攻 14 / 1.5s 一发 / 射程 3 格起步 / 血 100（电锯一半）/
    无减伤成长 / 耗电 6——输出换生存，被摸到就疼
  - 程序化拼装木质哨塔模型（零外部资产/零打包，材质克隆游戏设备自动匹配画风），弩机自动索敌
    转向 + 开火后坐 + 追踪式箭矢弹道（必命中表现层，伤害仍走官方结算）
- cfg 新增 `Defense.*` 13 键；版本号留作者定号（csproj Version 不动）
